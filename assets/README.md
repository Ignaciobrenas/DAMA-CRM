# 🎨 Directorio Global de Assets de DAMA-CRM

En este directorio se encuentran los recursos gráficos, vectores y logotipos del proyecto DAMA-CRM y las plantillas para la personalización de tu empresa (Marca Blanca).

---

## 📂 Directorios

* **`logos/`**: Logotipos en formato vectorial SVG y PNG transparente (versiones azul corporativo, blanco para modo oscuro y plantilla de ejemplo).
* **`branding/`**: Guías de estilo, paletas de colores corporativos e instrucciones para reemplazo rápido.

---

## 🔗 Vinculación con el Frontend Web

Los archivos públicos servidos directamente por el servidor web se encuentran en:
👉 `client/public/assets/`

Cualquier archivo colocado en `client/public/assets/logos/ejemplo.svg` puede ser referenciado en el CRM escribiendo `/assets/logos/ejemplo.svg` en el panel de **Ajustes > Identidad de Marca**.
